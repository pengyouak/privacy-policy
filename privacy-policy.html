AI XPath Tool 隐私政策

适用版本：v1.2.2 及以后 · 最后更新：2026-10-28
一句话概括：本扩展不收集、不上传、不转售任何个人数据。所有设置与历史记录只保存在你自己的浏览器里；只有当你主动配置了大模型 API 并点击「AI 生成」时，当前页面的元素结构摘要才会发送到你自己填写的那个 API 地址。

一、我们不收集什么

  • 不收集任何个人身份信息（姓名、邮箱、电话、账号）
  • 不含任何统计、埋点、崩溃上报或广告 SDK
  • 不向开发者或任何第三方服务器发送你的浏览记录、页面内容或生成结果
  • 不读取与元素定位无关的页面数据（如输入框内容、Cookie、密码字段值）

二、本地存储的数据

数据存放位置用途与保留
大模型配置（API 地址、模型名、API Key、温度、自定义提示词）chrome.storage.local（本机）仅用于发起你主动触发的生成请求；清除扩展数据或卸载即删除
最近 30 条生成历史（元素摘要、XPath、策略）chrome.storage.local（本机）方便复用；可在面板「清空」按钮一键删除

上述数据不会离开你的设备。API Key 未做云端备份，卸载扩展后无法恢复。

三、什么时候会向外部发送数据

仅在你同时满足以下条件时，扩展才会发起网络请求：

  • 你在设置页填写了 OpenAI 兼容的 API 地址与 Key；且
  • 你点击了「AI 生成 XPath」（或设置页的「测试连接」）

请求内容为：目标元素及其祖先链、同级兄弟元素的标签/属性/文本摘要，以及页面地址（用于让模型理解上下文）。请求直接发送到你填写的端点，不经过开发者服务器。该端点的数据处理行为受其自身隐私政策约束（例如你使用的是 OpenAI、DeepSeek、通义千问等服务商，或公司内网自建服务）。

如果你不配置任何 API，扩展全程离线运行：本地规则引擎完成 XPath 生成与验证，不产生任何网络请求。

四、页面访问权限如何使用

  • 脚本仅在你主动启动拾取、验证或高亮时读取页面 DOM 结构
  • 不使用键盘记录、不监听输入内容、不拦截页面数据请求
  • 冻结页面功能只是在窗口捕获阶段阻断鼠标/滚轮事件，用于固定悬浮菜单，不修改页面数据

五、数据删除

在扩展面板中点「清空」可删除历史记录；在设置页清空字段并保存可移除 API 配置；卸载扩展会删除全部本地数据。

六、儿童隐私

本扩展为开发者工具，不面向 13 岁以下儿童，也不收集任何年龄信息。

七、政策变更

若数据处理方式发生变化，会在本页面更新并修改上方「最后更新」日期；涉及新增数据收集时会在扩展更新说明中显著提示。

English Summary

AI XPath Tool does not collect, transmit, or sell any personal data. Settings (including your API key) and the last 30 generation records are stored only in your browser's local storage. Network requests occur solely when you have configured your own OpenAI-compatible endpoint and explicitly click "AI Generate": the request contains the target element's DOM summary and page URL, and is sent directly to the endpoint you configured — never to the developer. Without an API configuration, the extension runs fully offline. No analytics, no ads, no remote code.
